# Continuous assurance
Read-only Lovable inventory and GitHub metadata checks. Never invoke AI generation, connect repositories, change apps, merge, deploy or retry paid operations. Preserve existing product IDs; do not reassign based on list order. Match by exact unique name only as candidate, never proof. Confirm native Git connection and compare latest Lovable SHA with selected GitHub branch. Unknown is not disconnected. Record evidence and timestamp; report exceptions, request approval for remediation. Keep UUIDs, private repo names, secrets and billing data out of public reports. Dependencies require source inspection and are unassessed until verified.
